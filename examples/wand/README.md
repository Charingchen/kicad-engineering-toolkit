# Wand — candidate reference application

This is the first proposed application of the reusable toolkit. It is not a validated hardware design, firmware package, or assembly guide.

The intended use is a small controller-based device in a printed wand enclosure. The exact controller variant, power source, peripherals, dimensions, and acceptance criteria remain to be confirmed from the actual project records and received hardware. No pin assignments or battery compatibility are asserted here.

## Inputs needed

- Exact controller model/revision and manufacturer documentation.
- Desired behavior and observable acceptance tests.
- Parts already purchased, actual receipt status, quantities, and locations.
- Enclosure measurements or source CAD with units and clearance requirements.
- Power arrangement and its documented limits.

## First use of the toolkit

Create project records from the shared template, establish the first BOM, record materials, and plan an additional prototype with explicit spare targets. Record the first assembly and test results against its pinned BOM revision. Keep public examples synthetic until real project data has been reviewed for publication.

The example should exercise the same operations as any other project. Do not hardcode wand-specific parts or behavior into the core.
